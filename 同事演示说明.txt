公共资源交易智能监管 — 静态演示包
================================

1. 解压整个文件夹「智能监管页面」。

2. 启动本地服务（任选一种，在「智能监管页面」目录下执行）：

   python3 -m http.server 8777

   或（已安装 Node 时）：

   npm start

3. 浏览器打开（不要双击 html 文件）：

   http://127.0.0.1:8777/

   常用页面：
   - 驾驶舱：http://127.0.0.1:8777/cockpit.html?desk=fg
   - 预警列表：http://127.0.0.1:8777/warnings.html
   - 线索列表：http://127.0.0.1:8777/clues.html

4. 同办公室局域网演示：把 127.0.0.1 换成分享者电脑的局域网 IP。

更多说明见文件夹内 README.md
