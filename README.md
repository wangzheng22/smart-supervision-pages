# 公共资源交易智能监管演示页面

## 仓库

https://github.com/wangzheng22/smart-supervision-pages

## 在线访问（GitHub Pages）

在仓库 **Settings → Pages → Build and deployment** 中将 Source 设为 **GitHub Actions**，然后在 [Actions](https://github.com/wangzheng22/smart-supervision-pages/actions) 中重新运行失败的 “Deploy GitHub Pages” 工作流。部署成功后可用：

- 驾驶舱（发改）：https://wangzheng22.github.io/smart-supervision-pages/cockpit.html?desk=fg
- 线索回传：https://wangzheng22.github.io/smart-supervision-pages/clue-return.html
- 线索列表：https://wangzheng22.github.io/smart-supervision-pages/clues.html

## 临时演示链接（无需开启 Pages）

通过 jsDelivr 拉取 `main` 分支静态资源（有 CDN 缓存延迟，约数分钟）：

- https://cdn.jsdelivr.net/gh/wangzheng22/smart-supervision-pages@main/cockpit.html?desk=fg
- https://cdn.jsdelivr.net/gh/wangzheng22/smart-supervision-pages@main/clue-return.html
